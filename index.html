    📋 Dán tin nhắn Zalo Group

    Hướng dẫn: Mở Zalo PC → Vào group Support → Quét chọn nhiều tin nhắn → Ctrl+C → Dán vào ô bên dưới → Bấm AI Phân tích.
    AI sẽ tự lọc tin nhắn nào là sự cố IT, bỏ qua chat xã giao.

    💡 Mẹo sử dụng

    📌 Quét chọn: Click vào tin nhắn đầu → giữ Shift + click tin nhắn cuối → Ctrl+C
    📌 Mỗi lần dán: Nên dán khoảng 1-2 tuần tin nhắn (tránh quá dài AI bị giới hạn token)
    📌 AI tự lọc: Chỉ lấy tin báo lỗi, bỏ qua "ok", "cảm ơn", emoji, thông báo chung
    📌 Duyệt trước: Xem preview → bỏ tick dòng sai → rồi mới bấm Lưu

    🔗 Kết nối dữ liệu Chưa kết nối

    Dữ liệu nằm ở Google Sheet của công ty, không nằm trong trang này. Nhập link Web app (Apps Script) và mã truy cập để đồng bộ. Link và mã chỉ lưu trong trình duyệt của máy này.

    🤖 Nhà cung cấp AI

    📋 Hướng dẫn lấy khoá API

    🟣 Claude: console.anthropic.com → API Keys → Tạo khoá (bắt đầu sk-ant-)
    🟢 OpenAI: platform.openai.com → API Keys (bắt đầu sk-)
    🔵 Gemini: aistudio.google.com/apikey (bắt đầu AIza)
    🟠 Groq: console.groq.com → API Keys (bắt đầu gsk_)

    📥 Import dữ liệu từ Google Sheet

    Dán URL → chọn loại → bấm 🔍 Đọc & xem cột. Hệ thống tự nhận diện header sheet nguồn, hiển thị bảng mapping rồi mới import.

    Tính năng AI · 3 công cụ
    01 · AUTO-FILL
    Điền form từ mô tả
    Paste text tự do → AI tự tách ra phòng ban, triệu chứng, mức ưu tiên — không cần gõ tay.
    02 · BATCH EXTRACT
    Bóc tách Zalo hàng loạt
    Dán cả tuần tin nhắn nhóm → AI lọc rác, tạo Ticket từng dòng, lưu hàng loạt vào Sheet.
    03 · REPORT GEN
    Báo cáo giao ban tự động
    1 nút → thống kê sự cố, phân tích nguyên nhân, đề xuất tháng sau, xuất DOCX trình ký.
    Tính năng kỹ thuật
    Tính năng Ghi chú Trạng thái
    Đồng bộ 2 chiều Web ↔ Sheet Sửa web → Sheet cập nhật ngay. Sheet sửa tay → F5 hoặc Tải lại Realtime
    Inline Edit Click Ticket → popup sửa → Lưu. Không cần mở Sheet Có
    Smart Refresh Nút Làm mới tải cục bộ, không reload toàn trang Có
    Dark / Light Mode Công tắc ☀️/🌙, biểu đồ tự đổi màu theo Có
    Đa nhà cung cấp AI Claude · ChatGPT · Gemini · Groq — chuyển đổi 1 click 4 NCC
    Cảnh báo hết hạn License / bảo hành tự đổi màu Đỏ hoặc Cam Tự động
    Import từ Google Sheet Dán URL Sheet ngoài → tự nhận header, chống trùng Có
    Xuất file DOCX Tải thẳng từ trình duyệt sau khi AI soạn xong Có
    Hướng dẫn cấu hình ban đầu
    1
    Thiết lập AI Mở tab Cài đặt → chọn nhà cung cấp (Claude / ChatGPT / Gemini / Groq) → dán API Key → nhấn Kiểm tra kết nối.
    2
    Đồng bộ dữ liệu nguồn Trong tab Cài đặt → mục Import từ Google Sheet → dán URL Sheet ngoài (nếu có sẵn) → chọn loại dữ liệu → Import.
    3
    Sử dụng & làm mới Khi Sheet bị sửa thẳng bởi người khác → nhấn Tải lại toàn bộ dữ liệu trong Cài đặt, hoặc F5.
